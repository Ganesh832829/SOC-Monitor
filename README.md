# Linux SOC Monitor

A beginner-friendly Linux Bash project that collects important system information for basic SOC monitoring and security awareness.

## Features

- Displays system hostname and kernel information
- Identifies the current user and group privileges
- Lists running processes with PID and PPID
- Displays active system services
- Identifies sudo group members
- Displays scheduled Cron jobs

## Technologies Used

- Kali Linux
- Bash Scripting
- Linux Commands
- systemd
- Cron

## How to Run

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SOC-Monitor
chmod +x monitor.sh
./monitor.sh
```
